# دليل نظام الامتحانات للطالب

## نظرة عامة

تم إنشاء نظام شامل للامتحانات في تطبيق الطالب، يتضمن جميع الوظائف الأساسية لحل الامتحانات وعرض النتائج.

## الصفحات المتاحة

### 1. صفحة الامتحانات الرئيسية (`/exams`)
- عرض جميع الامتحانات المتاحة
- تصنيف الامتحانات (نشطة، قادمة، منتهية)
- عرض التقويم
- رابط سريع لنتائج الامتحانات

### 2. صفحة الامتحان (`/exams/[id]`)
- واجهة حل الامتحان مع جميع المميزات
- مؤقت زمني
- مراجعة الإجابات
- تأكيد الإرسال
- عرض تقدم الحل

### 3. صفحة النتائج (`/exams/results`)
- عرض جميع نتائج الامتحانات
- إحصائيات شاملة
- عرض شبكي وجدولي
- البحث والتصفية

### 4. صفحة تفاصيل النتيجة (`/exams/results/[id]`)
- تفاصيل شاملة لنتيجة امتحان واحد
- مراجعة الإجابات
- تحليل الأداء
- مقارنة مع الدرجة المطلوبة

## المميزات المتاحة

### حل الامتحان
- ✅ واجهة سهلة الاستخدام
- ✅ مؤقت زمني مع تنبيهات
- ✅ مراجعة الإجابات قبل الإرسال
- ✅ تأكيد الإرسال
- ✅ إرسال تلقائي عند انتهاء الوقت
- ✅ عرض تقدم الحل
- ✅ التنقل بين الأسئلة

### عرض النتائج
- ✅ إحصائيات شاملة
- ✅ عرض شبكي وجدولي
- ✅ البحث والتصفية
- ✅ تفاصيل كل نتيجة
- ✅ مراجعة الإجابات
- ✅ تحليل الأداء

### أنواع الأسئلة المدعومة
- ✅ اختيار من متعدد (Multiple Choice)
- ✅ صح أم خطأ (True/False)
- ✅ سؤال مقالي (Essay)
- ✅ اكمل الفراغ (Fill in the Blank)

## كيفية الاستخدام

### 1. حل امتحان
1. انتقل إلى `/exams`
2. اختر الامتحان المطلوب
3. اضغط على "بدء الاختبار"
4. اقرأ التعليمات والمعلومات
5. ابدأ في حل الأسئلة
6. استخدم أزرار التنقل للانتقال بين الأسئلة
7. اضغط على "مراجعة" لمراجعة إجاباتك
8. اضغط على "إنهاء الاختبار" عند الانتهاء
9. أكد الإرسال

### 2. عرض النتائج
1. انتقل إلى `/exams/results`
2. استكشف الإحصائيات الشاملة
3. استخدم البحث والتصفية للعثور على نتيجة معينة
4. اضغط على "عرض التفاصيل" لأي نتيجة
5. راجع إجاباتك وتحليل الأداء

### 3. مراجعة نتيجة معينة
1. من صفحة النتائج، اضغط على "عرض التفاصيل"
2. راجع الدرجة النهائية والحالة
3. اطلع على معلومات الامتحان
4. راجع تحليل الأداء
5. اضغط على "عرض التفاصيل" لمراجعة الإجابات
6. راجع كل سؤال وإجابتك والإجابة الصحيحة

## API Endpoints المستخدمة

```typescript
// جلب الامتحانات
quizApi.getByStudent(studentId)
quizApi.getById(quizId)

// إرسال الإجابات
submissionApi.create({ quizId, userId, answers })

// جلب النتائج
submissionApi.getByUser(userId)
submissionApi.getById(submissionId)
```

## أنواع البيانات (Interfaces)

### Quiz Interface
```typescript
interface Quiz {
  id: string;
  title: string;
  description?: string;
  lessonId: string;
  lesson: Lesson & { course: Course };
  questions: Question[];
  timeLimit?: number;
  passingScore?: number;
  maxAttempts?: number;
  showResultsImmediately: boolean;
  shuffleQuestions: boolean;
  shuffleAnswers: boolean;
  allowReview: boolean;
  createdAt: Date;
  updatedAt: Date;
}
```

### Submission Interface
```typescript
interface Submission {
  id: string;
  userId: string;
  user: User;
  quizId: string;
  quiz: Quiz;
  answers: any[];
  score?: number;
  feedback?: string;
  timeLimit?: number;
  passed?: boolean;
  createdAt: Date;
  updatedAt: Date;
}
```

## المميزات المتقدمة

### المؤقت الزمني
- عرض الوقت المتبقي بشكل واضح
- تنبيه عند اقتراب انتهاء الوقت
- إرسال تلقائي عند انتهاء الوقت
- تنسيق الوقت (ساعات:دقائق:ثواني)

### مراجعة الإجابات
- عرض جميع الأسئلة مع حالة الإجابة
- تمييز الأسئلة المجاب عليها
- تمييز الأسئلة غير المجاب عليها
- التنقل السريع بين الأسئلة

### تحليل الأداء
- نسبة الإجابات الصحيحة
- مقارنة مع الدرجة المطلوبة
- تحليل الوقت المستغرق
- تصنيف الأداء (ممتاز، جيد جداً، جيد، ضعيف)

### البحث والتصفية
- البحث في عنوان الامتحان
- البحث في اسم الكورس
- تصفية حسب الحالة (نجح/رسب)
- عرض شبكي وجدولي
